# Aireport Editorial Serif

`Aireport Editorial Serif SemiBold` is a report-specific subset derived from Adobe Source Han Serif SC SemiBold 2.003R.

- Upstream: https://github.com/adobe-fonts/source-han-serif/releases/tag/2.003R
- Upstream archive: `09_SourceHanSerifSC.zip`
- Upstream font: `OTF/SimplifiedChinese/SourceHanSerifSC-SemiBold.otf`
- Upstream OTF SHA-256: `faf16caeaf207e1926e01af8d9f1a8e71b0e9d8f51bf3b5d9a78f9f30e7e3e31`
- Output: `aireport-editorial-serif-semibold-subset.woff2`
- Output size: 339,588 bytes.
- Output SHA-256: `7d7470206c340f8cfa6e1984ef35094ffcb6c7091c3fbf964aaaa6e0ed235dac`
- Subset scope: report UI and rendered display-heading characters plus Basic Latin, General Punctuation and CJK punctuation.
- Modified family name: `Aireport Editorial Serif` (the upstream Reserved Font Name is not used for the derivative's primary family name).
- License: SIL Open Font License 1.1; see `OFL.txt`.

The subset is presentation-only. Missing glyphs fall back to the system serif stack declared in `report.css`.
