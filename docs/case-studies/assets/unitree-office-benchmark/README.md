## 目录

- `source-tree/AI办公评测/`：五家任务目录与复核材料中的非视频文件，保持打包时原始相对层级。
- `report/`：v4.5.1自包含原报告、活动数据、GitHub适配数据以及复算与最终QA材料；`release-v4.5/provenance-inputs/`仅保存活动数据直接引用的精确计算输入，不是另一个发布版本。
- `extracted-media/`：仅存在于报告显示层的媒体载荷。
- `external-snapshots/`：打包时取得的静态外部资料；不能冒充2026-08-30时点形成的独立证据。
- `stakeholder-responses/`：用户补充的5张工具自评回复原图及显示副本，均为非计分的事后陈述，不代表厂商正式立场。
- `manifests/`：逐文件来源、路径、哈希、重复组、外部链接与排除记录。
