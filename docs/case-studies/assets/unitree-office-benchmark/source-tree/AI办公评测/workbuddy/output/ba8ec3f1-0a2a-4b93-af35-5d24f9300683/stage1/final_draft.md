# 宇树科技（688836.SH）公司研究报告：人形机器人第一股的成长兑现与增速换挡

**报告性质**：公司研究（基于公开资料整理，非投资建议）　**数据截止**：2026年8月30日　**报告日期**：2026年9月4日

**摘要**：宇树科技于2026年8月19日登陆科创板，成为A股首家以人形机器人整机为主营业务的上市公司。2022-2025年公司营业收入由1.23亿元增至16.99亿元（CAGR约140%），2024年扭亏后盈利快速放大，2025年扣非归母净利润达5.91亿元、扣非净利率约34.8%，毛利率升至约60%，是全球人形机器人行业中少数实现规模化销售与盈利的公司。2026年上半年营收同比增长48.54%，增速较2025年明显换挡；同期研发费用同比增长约152%、销售费用超过2025年全年，扣非净利润同比下降19.34%，呈现阶段性的"增收不增利"特征。公司人形机器人2025年出货量超5,500台、居全球第一，收入占比过半；但下游场景仍以科研教育为主（2025年前三季度占比73.6%），工业化落地、竞争加剧与高估值消化是后续核心跟踪变量。

## 一、核心观点

1. **高成长已兑现，盈利质量行业稀缺**。2022-2025年营收复合增速约140%，2024年起扭亏为盈，2025年扣非归母净利润5.91亿元（同比+652.78%），主营业务毛利率由44.18%升至约60.3%；在普遍"增收不增利"的具身智能行业，公司是少数实现规模化盈利的样本。
2. **收入结构完成切换，人形机器人成为第一引擎**。人形机器人收入占比由2023年的1.88%升至2025年的51.07%，2025年出货量超5,500台、居全球第一；境内收入占比2025年升至55.58%，扭转了此前境外占比过半的格局。
3. **2026年进入"增速换挡+费用前置"阶段**。2026年上半年营收同比+48.54%（2025年为+333%），研发费用同比+152%、销售费用超2025年全年，扣非净利润同比-19.34%；公司归因于营收基数抬升、行业热度缓和、竞争加剧及研发与品牌投入前置。
4. **关键跟踪变量**：人形机器人工业/商用场景的订单兑现、毛利率走势（2026H1已回落至56.01%）、费用率回归节奏，以及约219倍发行市盈率对应的估值消化压力。

## 二、主营业务与产品结构

### 2.1 公司概况

宇树科技股份有限公司（证券代码688836.SH，简称"宇树科技-W"）是一家高性能通用机器人公司，专注于高性能通用人形机器人、四足机器人、机器人组件及具身智能模型的研发、生产和销售。据公司公告（2026年8月），公司前身宇树有限成立于2016年8月26日，2025年5月28日整体变更设立股份公司，2026年正值成立十周年。

公司IPO进程紧凑：2026年3月20日科创板IPO申请获上交所受理（为科创板"预先审阅"机制第二单），2026年6月1日通过上市委会议审议，2026年8月19日正式上市。本次发行新股不低于4,044.64万股，发行价150.80元/股，发行市盈率约219倍，拟募集资金42.02亿元，投向智能机器人模型研发、机器人本体研发、新型智能机器人产品开发及智能机器人制造基地建设四大项目。上市首日开盘1,100元/股（较发行价+629.44%），收盘845元/股，换手率85.28%，成交额231.60亿元。

股权结构方面，据招股说明书（2026年3月），创始人王兴兴直接持有公司23.8216%的股份，为控股股东、实际控制人；据媒体披露（证券时报，2026年3月），其控制近七成表决权，机构股东涵盖美团、蚂蚁集团、红杉中国、腾讯、阿里等。

### 2.2 产品矩阵

公司产品体系呈"人形+四足+组件"三层结构：

- **人形机器人**：2023年8月推出首款通用人形机器人H1，2024年推出中型人形机器人G1并快速成为主力销售产品，其后又发布R1、H2等型号，目前已自研发布四款系列人形机器人（不含轮式）。产品应用于科学研究、应用开发、教育教学、文化表演、智能服务等场景。
- **四足机器人**：B系列行业级产品（B1/B2/B2-W等）与Go系列消费级产品（Go1/Go2/Go2-W、A2等），广泛应用于科学研究、工业巡检、应急救援、智能服务等领域，是公司最早建立优势的业务。
- **机器人组件**：关节模组、灵巧手、协作机械臂、感知传感器等核心部组件，既自用也对外销售，构成生态收入。

技术渊源上，公司四足机器人的核心方案源自王兴兴硕士期间研制的全球首款低成本外转子无刷电机驱动四足机器人XDog。公司在运动表现与拟人化水平、抗冲击抗摔打能力、产品鲁棒性和集群调度能力等方面形成了差异化优势。

### 2.3 收入结构：人形反超四足，境内反超境外

**产品结构方面**，人形机器人收入占比由2023年的1.88%（H1上市当年）快速提升至2024年的27.6%、2025年前三季度的51.53%（当期人形收入5.95亿元，同比+642.38%，首次反超四足）；据2025年年度报告，全年人形机器人收入8.68亿元、占比51.07%，四足机器人收入6.98亿元、占比41.05%，机器人组件收入1.04亿元、占比6.10%，人形机器人正式成为第一大收入来源。

**销量方面**，据招股说明书，2022年至2025年9月公司四足机器人累计销量超3万台；2025年前三季度人形机器人销量3,551台（同比+1054.8%）；2025年全年人形机器人出货量超5,500台（纯人形，不含轮式双臂机器人），出货量全球第一。值得注意的是，随着G1等中低价位产品占比提升及公司主动下调产品价格，机器人销售均价连年下降，公司以价换量、做大规模摊薄成本的策略特征明显。

**地域结构方面**，2022-2024年公司境外收入占比均超50%；2025年年初央视春晚人形机器人演出后，公司在国内的品牌知名度与关注度持续提升，境内市场快速打开——2025年前三季度境内收入占比升至60.8%，全年境内收入9.44亿元、占比55.58%，境外收入7.32亿元、占比43.06%，市场重心由海外转向国内。

公司2024年实现扭亏（归母净利润9,450.18万元），2025年盈利快速放大（归母约2.78亿元、扣非5.91亿元）。需要特别说明的是口径问题：2025年公司确认了非经常性损益性质的股份支付费用34,906.55万元（股权激励平台上海宇翼增资，主要在2025年上半年确认），导致2025年上半年归母净利润为-3,202.45万元而扣非净利润为正，归母与扣非口径差异显著，阅读利润数据时须区分。

2026年上半年，公司归母净利润2.74亿元（较上年同期扭亏），但扣非净利润2.44亿元、同比下降19.34%；一季度扣非净利润4,025.36万元、同比下降52.55%。据上市公告书，扣非下滑主要系研发费用、销售费用等期间费用同比增幅较大所致。分季度看，据招股书业绩预告区间推算，2026年二季度扣非净利率已回升至31.11%-34.42%区间，较一季度的约9.5%明显修复，费用前置的影响集中在一季度。

### 3.3 盈利质量：毛利率升至60%后小幅回落

公司主营业务毛利率由2022年的44.18%、2023年的44.22%提升至2024年的56.41%、2025年的约60.3%（整体销售毛利率口径2025年为60.44%），扣非净利率2025年约34.8%。毛利率抬升的核心驱动：一是人形机器人放量带来的规模效应，人形机器人毛利率2023年高达87.7%，2024年为68.4%，2025年前三季度随G1量产与主动降价收窄至62.9%，但仍显著高于整体水平；二是核心部组件自研自产带来的成本下降，机器人组件毛利率由2023年的48.8%升至2025年前三季度的60.4%。

2026年毛利率小幅回落：整体销售毛利率一季度58.42%、上半年56.01%。背后既有产品价格下调，也有市场竞争加剧的影响，毛利率走势是判断公司"以价换量"策略可持续性的核心指标。

### 3.4 现金流与资产负债

盈利具备现金流支撑：2025年公司经营活动现金净流入超6.7亿元，较2024年增加约4.8亿元（据招股书，主要系收入规模快速增长）。截至2026年6月30日，公司资产总额38.45亿元（较2025年末增长19.85%），其中流动资产28.88亿元（增长30.13%），叠加IPO募集资金到位，资金面稳健，为研发投入提供了充足弹药。

## 四、研发投入分析

**投入强度快速抬升，但横向对比仍偏低。** 公司研发费用2023年为4,995.18万元（占营收31.4%）、2024年约6,983万元（按17.8%费用率推算）、2025年14,496.56万元（占营收8.53%）、2026年上半年13,590.65万元（同比+152%，半年投入已接近2025年全年）。费用结构上，职工薪酬占研发费用约八成；2025年前三季度云算力租赁及云服务费增至835万元，为2024年全年（113万元）的近8倍，反映公司正加大具身智能大模型方向的算力投入。

**研发投入的结构性含义**：据公司披露（上市公告书，2026年8月），公司在本体与结构研发、具身智能大模型、运动控制算法等领域持续加大投入并扩充研发团队。市场分析认为，公司传统强项在机器人本体、关节、电机与运动控制（业内所谓"小脑"），而具身大模型、视觉感知、任务规划等"大脑"能力需要补课，这是2026年研发费用大幅增长的深层原因。横向看，据证券时报（2026年）转引数据，优必选2025年研发支出5.1亿元、占收入超25%，越疆研发支出1.15亿元、占收入约23%，科创板企业2025年前三季度研发投入占营收比例中位数为12.5%——宇树2025年研发费用率8.53%明显偏低，2026年的研发投入加码既是主动布局，也是竞争压力下的必然选择。本次IPO拟募资42.02亿元，其中三个机器人研发类项目合计约36亿元，将为研发持续投入提供资金保障。

## 五、竞争优势

1. **全栈自研自产与成本控制能力**。公司在答复上交所问询中表示，通过核心部组件自研自产、逐步建立自有产线，实现对供应链的深度掌控，既保障产品与技术快速迭代，也显著降低物料采购与制造成本；公司已成为机器人领域产品定价的锚定者。这是其毛利率显著高于可比公司（优必选、越疆）的根本原因。
2. **规模化盈利的稀缺性**。在普遍亏损烧钱的人形机器人行业，公司2024年起持续盈利，2025年扣非净利率约34.8%，经营现金流同步验证盈利质量，是全球少数实现"规模化销售+盈利"的机器人公司。
3. **出货量全球领先的规模优势**。四足机器人累计销量超3万台（2022-2025年9月），2025年人形机器人出货超5,500台、居全球第一；规模化出货带来的数据积累、供应链议价与品牌认知形成正循环。据21世纪经济报道（2026年9月）转引，海外头部公司Figure AI 2025年出货量约150台，仅为宇树的约1/36。
4. **品牌与渠道势能**。2025年央视春晚人形机器人演出实现"一战成名"，公司直言受益于品牌知名度提升，境内市场快速打开，2026年延续春晚等品牌推广策略。
5. **资金与股东资源**。IPO募资42.02亿元到账，叠加美团、蚂蚁、红杉中国、腾讯、阿里等产业与财务股东资源，为研发、产能与生态扩张提供支撑。

## 六、增长变量

1. **人形机器人从科教走向工业/商用（最关键变量）**。当前公司下游高度集中于科研教育（2025年前三季度占人形收入73.6%），工业场景需要现场测试、软件适配、系统集成和持续售后，获客与交付成本更高（2026年上半年销售费用激增已部分反映这一转型成本）。工业订单的实质性放量将决定营收能否重回高增长。
2. **具身智能"大脑"能力的补强进度**。募投约36亿元投向三个研发项目，具身大模型与运动控制的融合进度决定产品能否从"表演与科研"升级为"可干活的通用机器人"。
3. **海外市场渗透**。境外收入占比2025年为43.06%，仍是最重要的收入来源之一；海外科研与开发者市场具备先发优势，但需关注贸易环境变化。
4. **产品矩阵与组件生态扩张**。轮式双臂机器人、灵巧手、协作机械臂等新品与组件业务（毛利率60%+）有望贡献第二增长曲线。
5. **价格策略与毛利率的平衡**。公司以价换量做大规模，2026年上半年毛利率已回落至56.01%；若降价无法换来足够销量弹性，盈利中枢将下移。

需要特别提示的是，市场机构对公司未来收入已有较高预期：据媒体转引（未经研报原文核验），野村预计2026-2028年营收分别为26.87亿、53.96亿、131.84亿元，招商证券预计分别为30.97亿、49.60亿、76.83亿元。**上述均为机构预测，非已发生事实**，且不同机构预测分歧较大，仅供参考方向，不应作为估值的确定依据。作为对照，公司2026年上半年实际营收11.52亿元，已超出招股书业绩预告区间上限（10.52-11.28亿元），实际扣非净利润2.44亿元落在预告区间内（2.36-2.83亿元）。

## 七、风险提示

1. **行业竞争加剧导致份额与利润率承压的风险**。国内多家整车制造企业与消费电子企业已正式布局人形机器人业务，智元、优必选等加速推进工业场景量产，海外特斯拉等持续加码。若竞争者在资源投入、市场推广与制造经验上的优势兑现，公司可能在产品定价、市场份额及利润率水平上承受压力，触发条件为竞争者工业级产品批量上市。
2. **业绩增速放缓与盈利波动的风险**。2026年上半年营收增速已降至48.54%（2025年为+333%），扣非净利润同比下降19.34%；若行业热度进一步降温或费用投入持续前置，全年盈利增速可能继续低于市场预期，触发条件为后续季度扣非净利率无法回到30%以上水平（该阈值为基于招股书业绩预告区间的分析判断，非公司承诺指标）。
